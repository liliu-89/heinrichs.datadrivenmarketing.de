# Heinrichs · E-Commerce Performance & Multichannel-Wachstum

16:9-Präsentation für den zweiten Austausch mit der Handelshaus Heinrichs GmbH & Co. KG.

- [`index.html`](index.html) — die Präsentation (7 Slides, eine einzige selbsttragende Datei)

## Bedienung

| Aktion | Taste |
|---|---|
| Blättern | ← / → · Leertaste · Bild auf/ab |
| Erste / letzte Slide | Pos1 / Ende |
| Speaker Notes | `N` |
| PDF-Export | Button unten links (Browser-Druck, ergibt exakt 7 Seiten) |

## Technik

Eine Datei, keine externen Requests, kein Build-Schritt. Markenschriften
(Loretta, ITC Franklin Gothic) und Logo sind als base64 bzw. Inline-SVG
eingebettet. Farben und Typografie folgen den DDM Design Guidelines.

Die Seite ist per `<meta name="robots" content="noindex, nofollow">` von der
Suchmaschinen-Indexierung ausgenommen, über den direkten Link aber öffentlich
erreichbar.
